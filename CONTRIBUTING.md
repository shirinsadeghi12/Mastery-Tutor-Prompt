# Contributing

Welcome! Useful contributions:

- 🐞 **Bug reports**: include the model name, your CONFIG, and the exact output that broke a rule.
- 🌍 **Translations** of the prompt or docs
- 🧪 **Test cases**: input + expected behavior (e.g. "after 3 ❌ answers, tutor must slow down")
- 📚 **Mode examples** for new subjects (math, programming, medicine, music)

Rules:
1. Keep the five non-negotiable rules intact (honesty, evidence, logic, pacing, format).
2. Cite a source for any pedagogical claim you add to `docs/`.
3. Describe model + version when you report that something works or fails.
