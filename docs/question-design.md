# 🎯 Designing the three questions

## Ladder (revised Bloom's taxonomy)

| Level | Verb examples | Used in |
|---|---|---|
| Remember | define, list | ❌ not allowed as a main question |
| Understand | explain in own words | warm-up only |
| **Apply** | use, solve, produce | Q1 |
| **Analyze** | diagnose, compare, find the flaw | Q2 |
| **Evaluate / Create** | justify, design, predict | Q3 |

## Quality checklist (for contributors)

- [ ] Can't be answered by copying a sentence from the lecture
- [ ] Requires a context or numbers the lecture did not use
- [ ] Has a defensible correct answer (or a clear rubric)
- [ ] Q1 < Q2 < Q3 in difficulty
- [ ] Not yes/no

## Worked vs. open problems
Novices learn faster from worked examples, then partially completed ones, then full problems.
Experts do better with problems alone, and extra guidance can hurt them.
The prompt's adaptation engine fades scaffolding as accuracy rises.

## Interleaving
At checkpoints, mix topics instead of grouping by chapter. It feels harder and produces better discrimination
between similar concepts.
