# 💾 STATE BLOCK template

Paste this at the start of a new session (below the prompt). Edit freely; the tutor reads it as-is.

```
STATE v1
session: 0
position: "none"
level_note: "starting"
recent_scores: []
weak_points: []
graduated: []
cards:
| ID | Box | Last | Front | Back | Tag |
|----|-----|------|-------|------|-----|
```

Tips:
- Save each exported block in a file such as `my-progress/book-name.md`.
- If the model's output looks wrong (a card in the wrong box), fix the table by hand. You are the source of truth.
